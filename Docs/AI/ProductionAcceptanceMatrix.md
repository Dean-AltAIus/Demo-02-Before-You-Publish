# Production acceptance matrix

The [CSV matrix](ProductionAcceptanceMatrix.csv) maps all 155 source-manifest items to saved content or explicitly scoped preparation, relevant states and observed evidence. It preserves the distinction between a candidate path and accepted content. The private local JSON additionally retains source and content hashes and the original candidate annotations.

There are 147 required items, one conditional item, three optional items and four gated future items. At this checkpoint, 146 required content rows pass their stated checks; the world row retains a failed rendered-performance gate. The conditional texture workflow passes. All three optional items and four gated Arabic/voice items are unverified. The two buyer items have precise saved presenter equivalents, but their item-specific display and control checks timed out before acceptance; optional ambience is omitted. The required loading row has a separate passed native cancel, rapid retry, unavailable, recovery and actual visual receipt at 1280, 1920 and 2560 at 100%, plus 1280 at 200%. The first Player diagnostic failed its rendering guard. A separately authorized isolated-desktop run rendered successfully, but courtyard and marking still failed the frame-time target. A later bounded Editor comparison reduced draw and batch counts with GPU Resident Drawer, but all three candidate p95 values still failed and the candidate was restored. Dean chose current image quality with the measured performance limitation documented. This is a delivery direction with an explicit failed engineering gate, not all-gates acceptance.

`passed` means the row's bounded content and interaction checks have evidence. It does not independently certify the entire game, live semantic assessment, learning transfer, on-screen hardware behavior or an unmeasured device. `failed` retains a concrete unmet check. `unverified` is explicit for omitted content, future gates or saved optional content without item-specific runtime proof. Source freshness is not runtime acceptance.

Evidence paths under `LocalOnly/Validation` identify retained local inspection records and original captures. Those artifacts are intentionally excluded from Git; the matrix is a public-safe index, not a claim that the private evidence is portable with the source checkout. [IntegratedAcceptance.md](IntegratedAcceptance.md) records the actual methods, results and remaining limits. Earlier candidate and rejected iterations in the production ledger remain historical.

Supplied character inputs, generated derivatives and the existing canonical Leena package retain their source receipts. The retained Meshy walking file incorporates the action into the generated learner output; it is distinct from a standalone animation library. No raw Mixamo redistribution is admitted. The four preparation documents and private developer pack are not newly copied into runtime or public source delivery.
